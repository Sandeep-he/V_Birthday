Start the site:
1. Keep Node.js installed.
2. Copy .env.example to a file named .env.
3. If you want wish email notifications, put your Gmail App Password in SMTP_PASS. SMTP is set to port 465 (SSL), which was confirmed working in your tests.
4. Double-click START_SERVER.bat and keep its terminal open.
5. Visit http://localhost:5501. Do not use Live Server on port 5500 for the wish/email feature.

Security note: The ZIP intentionally does not include your real .env password. Keep .env private.
